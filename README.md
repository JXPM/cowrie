# Cowrie

Application de budget mensuel, 100 % statique (un seul fichier `index.html`).

- Revenus, dépenses fixes (avec case « payé »), vie quotidienne, épargne
- Suivi de l'épargne mois par mois, objectifs, historique de la marge
- Installable sur téléphone (PWA), données enregistrées dans le navigateur (`localStorage`)

## Déploiement

Hébergée sur Vercel, connectée à ce repo : chaque `git push` sur `main` redéploie automatiquement.
